# taiga-front (nakomis fork)

This is a fork of [taigaio/taiga-front](https://github.com/taigaio/taiga-front), forked at v6.10.0 (commit `12ee02efa`).

## Upstream

The upstream remote is `taigaio`. To fetch upstream changes:

```bash
git fetch upstream
git merge upstream/main
```

Branches keep upstream naming — the default branch is `main`.

## Customisations

All planned customisations are tracked as user stories in the Taiga project management instance. Refer there for what has been changed and why.
